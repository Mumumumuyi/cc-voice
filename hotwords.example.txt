# 热词表模板。首次启动时会复制成 hotwords.txt —— 那份是你自己的词表，不入库（见 .gitignore），
# 放心写项目代号、人名这类私人词汇。一行一个，中英文都行。改完在管理面板点「保存设置」，
# 几秒后生效（LLM 模型要重载）。
#
# 它同时起两个作用：
#   1. funasr-nano-llm 会把这张表写进提示词，识别时就往这些词上靠 —— 治专有名词
#   2. 识别完再按「模糊音」逐字比对（平翘舌、n/l、前后鼻音不分），把读音相同/相近的
#      片段改成热词 —— 治口音。例：「深度学系」->「深度学习」、「数据酷」->「数据库」
#
# 放什么：你反复说、而模型总听错的词 —— 项目代号、工具名、你领域里的术语。
# 别放模型本来就认得的词：热词会变成「磁铁」，把没听清的近音词吸过去。实测一个模型本来
# 全对的英文缩写放进来后，反而把别的短英文词也识别成了它；拿掉后字错率 2.40% -> 1.36%。
# 所以：某个热词开始出现在你没说它的地方，就把它删掉。表越长每句也越慢。
# 不会误改：窗口本身是常用词就不动（「借口」不会被改成「接口」）。
